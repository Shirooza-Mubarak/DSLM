# PI stage dependencies

## Files to obtain separately

Obtain a compatible PI GCS2 SDK from Physik Instrumente or the authorized support channel for your controllers. Place these files directly in StageFiles. 

Install the appropriate PI controller and USB drivers using the manufacturer's installation procedure.

## Compatibility

Use matching x64 SDK libraries and drivers for your controllers.

Verify the controller-to-axis mapping before operating the stages.
The application selects controllers using USB enumeration order.

## Distribution

PI SDK files and runtime components are external dependencies excluded from this public source distribution.

Obtain and use them under their applicable license.
