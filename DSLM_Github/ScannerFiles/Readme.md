# SCANLAB RTC5 dependencies

## Files to obtain separately

Obtain a compatible RTC5 SDK, firmware, and drivers from SCANLAB or its authorized support channel.

Place these files directly in ScannerFiles. Also place the appropriate scanner correction table, .dat, .out, .rbf files in this folder, as required by the code.

Install the RTC5 board driver using the manufacturer's installation procedure.

## Compatibility

Use compatible x64 libraries, firmware, and drivers for your RTC5 board.
The correction table must be appropriate for your scanner configuration.

## Distribution

SCANLAB SDK files, runtime components, firmware, and correction tables are external dependencies excluded from this public source distribution.

Obtain and use them under their applicable license.
